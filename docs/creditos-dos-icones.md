# Créditos dos ícones

O diagrama usa os ícones oficiais AWS Architecture Icons do pacote de julho de 2026. Os símbolos pertencem à Amazon Web Services. Fonte: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/). As caixas, rótulos e conexões foram reorganizados para o laboratório de Marcos Mendes.

A composição segue a referência fornecida pelo autor. Os dados de região, nome e CIDR da VPC, os dois NAT Gateways zonais e o uso de Session Manager integram o projeto de Marcos Mendes. Autoria do projeto Marcos Mendes.
